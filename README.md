# 양극산화피막 불량 조기경보 시스템

내일배움캠프 실전 프로젝트 — 방산 부품(소총·탄피) 표면처리 공정의 전압·전류·온도 센서만으로 양극산화피막 불량을 자동 분류하고 이상 시점을 추적하는 시스템

- **팀**: 5인 · 2026.05
- **담당**: 통계 검정 · 파생변수 · 모델링

## 문제

방산 부품 표면처리사의 양극산화 라인은 검사를 공정 완료 **후**에 수행해, 환경·약품 변화로 인한 불량을 뒤늦게 발견하고 재작업·폐기·납기 리스크가 누적된다. 전압·전류·온도 3종 센서만으로 시퀀스(공정 1회분) 단위 불량을 실시간 분류하는 것이 목표.

- 데이터: `방산.csv` 96,901행(5초 간격 센서) + 라벨 100 시퀀스(정상 89 · 불량 11, **11% 불균형**)
- 시퀀스 그룹 단위로 분할해 데이터 누수 차단

## 접근

1. **EDA 핵심 통찰**: 불량은 전류·전력·전압이 양방향으로 분산돼 단방향 평균으로는 상쇄됨 → **정상기준 절대이탈(|z|)** 로 전환해야 분리됨. 이 통찰이 성능 정체를 돌파한 지점.
2. **통계 검정**(Mann-Whitney U + BH-FDR 다중비교 보정)으로 `ampere_mean_absz`, `hot_amp_absz`, `power_mean_absz`, `volt_mean_absz` 등 유의 변수를 확정하고, 모델 성능은 순열검정으로 재확증
3. 파생변수 30개 → VIF로 다중공선성 제거 → **컴팩트 5피처**로 압축 (PR-AUC 0.41 → 0.91)
4. **LOO-CV**로 로지스틱 회귀·XGBoost·RandomForest 비교, **이상탐지(LOF/OneClassSVM/IsolationForest)와 교차검증**해 지도학습 결과의 신뢰성 확보
5. 미탐 비용이 오탐 비용보다 훨씬 크다는 판단 하에 **임계값을 0.4391로 재설계** → 재현율 100% 달성

## 결과

|---|:--:|:--:|---|
| **로지스틱 회귀** ⭐ | 0.991 | **0.944** | 채택 — 소표본 과적합 적음, 해석·배포 단순 |
| XGBoost | 0.982 | 0.875 | |
| RandomForest | 0.951 | 0.755 | |

- **재현율 100%(11/11, 미탐 0건)**, 오탐률 7%
- 이상탐지 교차검증: **LOF AUC 1.000** — 이상 점수 급등 시점의 전류 이탈이 지도학습 원인변수와 일치
- **Streamlit 대시보드**로 불량 판정 + 규칙 기반 불량유형 추정 + SPC 넬슨 규칙 5종 실시간 이상점수 + ROC/PR 운영화
